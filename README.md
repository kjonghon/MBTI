# MINDMETRIC

MINDMETRIC은 네 가지 선호 축을 돌아보는 비공식 자기성찰 도구입니다. 16개 자체 구성 문항으로 응답 기반 경향 점수와 설명을 제공합니다.

## 사이트

- 서비스: <https://kjonghon.github.io/MBTI/>
- 검사 방법과 한계: 홈페이지의 “검사 방법과 한계” 안내
- 개인정보 및 광고 안내: [privacy.html](./privacy.html)
- AdSense 게시자 정보: [ads.txt](./ads.txt)

## 범위와 한계

이 문항은 표준화 표본으로 보정되거나 신뢰도·타당도 검증을 거치지 않았습니다. 임상 진단, 공식 MBTI® 검사, 채용 또는 진로 적합성 평가가 아닙니다. 점수 계산 방식과 유의사항은 사이트에서 확인할 수 있습니다.

## 구현

별도의 빌드 단계가 없는 정적 사이트이며 GitHub Pages에서 `main` 브랜치 루트를 게시합니다. 기본 언어는 러시아어이며 카자흐어, 영어, 스페인어, 중국어, 아랍어로 전환할 수 있습니다. 선택 언어와 테마는 브라우저 로컬 저장소에 저장되고 검사 응답은 브라우저에서만 계산됩니다. 광고는 Google AdSense를 사용합니다.
